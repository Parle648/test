## [BE] POST эндпоинт, отсуствует валидация для поля sellerId

### Приоритет

**High** - система не справляется со своей основной функцией

### Шаги воспроизведения

1. Выполнить POST запрос передав следующий JSON объект

```json
{
  "sellerID": -5151,
  "name": "asd",
  "price": 300,
  "statistics": {
    "likes": 1,
    "viewCount": 1,
    "contacts": 1
  }
}
```

### Фактический результат

- В ответе:

```json
{
  "status": "Сохранили объявление - (id созданного объявления)"
}
```

### Ожидаемый результат

- В ответе:

```json
{
  "result": {
    "message": "sellerID должен быть числом в диапазоне 111111-999999"
  },
  "status": 400
}
```

### Пояснение

Это баг, поскольку идентификатор не может быть отрицательным числом

## [BE] GET эндпоинт поиска обьявления по его идентификатору должен возвращать объект

### Приоритет

**Medium** - Это ошибка в проектировании API, если FE под это уже готов, то это не критично

### Шаги воспроизведения

1. Выполнить GET запрос по адресу {{baseUrl}}/api/1/item/{id существующего объявления}

- В ответе:

```json

  {

    "id": "идентификатор искомого объявления",

    "price": "цена int",

      "likes": "лайки int",

    }
  }
]
```

- статус 200

### Ожидаемый результат

- В ответе:

```json
{
  "createdAt": "строка даты",
  "id": "идентификатор искомого объявления",
  "name": "имя объявления",
  "price": "цена int",
  "sellerId": "идентификатор продавца",
```

## [BE] GET эндпоинт поиска статистики объявления для удаленного объявления не возвращает ошибку

### Приоритет

**High** - здесь ломается бизнес-логика

### Шаги воспроизведения

1. Выполнить DELETE запрос по адресу {{baseUrl}}/api/2/item/{id объекта}
2. Убедится, что объявление удалено
3. Выполнить GET запрос по адресу {{baseUrl}}/api/1/statistic/{id удалённого объекта}

### Фактический результат

- В ответе:

```json
[
  {
    "contacts": "<количество контактов int>",
    "likes": "<количество лайков int>",
    "viewCount": "<количество просмотров int>"
  }
]
```

- статус 200

### Ожидаемый результат

- В ответе:

```json
{
  "result": {
    "message": "такого объявления не существует",
    "messages": {
      "item": "объявления с таким id не существует"
    }
  },
  "status": "404"
}
```

- статус - 404

### Пояснение

Здесь ошибка комплексная, во первых после удаления объявления статистика для этого объявления не должна выводится, во вторых, когда id невалидный - message неинформативный, messages - пустой.
