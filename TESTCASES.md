## Проверка успешного создания объявления пользователем

### Предусловие:

- Сервер API доступен по адресу [https://qa-internship.avito.com](https://qa-internship.avito.com)
- Подготовлены корректные данные для создания объявления
- Пользователь с sellerID = 222222 существует в системе

### Шаги проверки

1. Отправить POST запрос на {{baseUrl}}/api/1/item
2. body должно иметь следующий вид

```
{
  "sellerID": 222222,
  "name": "Парле",
  "price": 300,
  "statistics": {
    "likes": 1,
    "viewCount": 100,
    "contacts": 1
  }
}
```

3. Установить заголовки:
   - Content-Type: application/json
   - Accept: application/json

### Ожидаемый результат

- HTTP статус 201 ОК
- Тело JSON объекта:

```
{
    "status": "Сохранили объявление - <id созданного объявления>"
}
```

### Постусловие

- Сохранить полученный ID объявления
- Убедиться, что возвращаются те же данные объявления
- При необходимости удалить тестовое объявление через DELETE /api/2/item/{id}

````markdown
# Тест-кейсы валидации данных при создании объявления

## TC-VALID-001: Валидация обязательного поля sellerID

### Предусловие:

- Сервер API доступен по адресу https://qa-internship.avito.com

### Шаги проверки:

1. Отправить POST запрос на {{baseUrl}}/api/1/item
2. В теле запроса передать данные без поля sellerID:

```json
{
  "name": "Парле",
  "price": 300,
  "statistics": {
    "likes": 1,
    "viewCount": 100,
    "contacts": 1
  }
}
```
````

3. Установить заголовки:
   - Content-Type: application/json
   - Accept: application/json

### Ожидаемый результат:

- HTTP статус код: 400 Bad Request
- Тело ответа содержит JSON с описанием ошибки валидации
- В сообщении ошибки указано, что поле sellerID обязательно

### Постусловие:

- Убедиться, что объявление не было создано
